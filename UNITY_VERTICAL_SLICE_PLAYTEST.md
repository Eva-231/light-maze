# LIGHT MAZE Unity Vertical Slice — Playtest

This branch now contains a code-driven first playable for the Unity migration.

## Open the canonical Unity project

Use Unity Hub to add/open:

`C:\UnityProjects\light-maze\UnityProject`

The older `C:\UnityProjects\LightMazeUnity` folder was only used to bootstrap the URP project and is no longer the canonical working copy.

## Before opening

In GitHub Desktop:

1. Select repository `light-maze`.
2. Select branch `unity-vertical-slice`.
3. Fetch origin / Pull origin until there are no incoming commits.

## Play

Open `Assets/Scenes/SampleScene.unity` and press Play.

The runtime bootstrap builds a dark-blue Abyss chamber automatically and spawns:

- Explorer protagonist with white/silver/black visual language and blue-white LIGHT core
- Shadow Soldier
- Rift Wolf with quadruped silhouette
- Abyss Guardian
- HP / MP / LIGHT HUD
- Light Bolt
- room-wide Ice Nova
- Heal
- third-person camera
- sprint and dodge
- enemy chase/contact combat
- procedural hit, ice, heal and death effects

## Controls

- `WASD`: move
- `Shift`: sprint
- `Space`: dodge
- Mouse: camera
- `Left click` or `J`: Light Bolt
- `Q`: Ice Nova
- `E`: Heal
- `Esc`: unlock cursor
- `R`: restart after defeat

## Art direction

This is a gameplay/lighting/VFX foundation, not final character art. The target remains the approved LIGHT MAZE reference: white-haired explorer, black/silver armor, pale cloth, blue-white LIGHT core, blue-black maze, red/purple/blue/gold enemy accents, and strong luminous combat effects against a dark environment.
