# 主人公モデル交換・実画面レビュー（2026-10-11）

現行GanzSe主人公は最終採用しない。価格ではなく、ローポリの造形・髪・顔の構造が目標と異なる。

Unity 6000.5.11f1の実際のPlay Modeを確認し、既存のExplorer portrait機能で撮影した。画像はこのチャットのoutputs/current-hero-gameview.png。新モデルの画像や完成予想図ではない。撮影時はゲームを一時停止している。

実画面での問題:
- 顔は平面的な多角形で、目・口・頬の自然な立体感が不足。顔に十分な光が届いていない。
- 髪が白い一体型の塊で、毛束・透け・暗色センターパートという目標と異なる。
- 肩の大きな金属突起、厚い装甲、硬い裾が軽装の端正なシルエットと異なる。
- 金属以外の肌・髪・布の材質差が読み取りにくい。

## 制作経路の比較

|経路|費用・確認状況|今回の判断|
|---|---|---|
|Blenderによる制作|ソフトは無料。素材は個別の利用条件を確認|精密造形は可能だが、顔の制作・リトポロジー・髪・衣服・スキニングの作業を省略できない|
|MetaHumanの人物ベースをUnityへ移植|公式は年間売上100万米ドル未満で無料、他エンジン利用可と説明|無料案の有力候補。Unityゲーム自体のエンジンは維持。髪・衣装・マテリアル・骨格の移植検証が必要で、まだ導入していない|
|Character Creator|CC 365 Standardの公式検索掲載は年額99米ドル。税・追加コンテンツ別。購入時の表示価格を再確認|人物編集・Unity導入工程を短縮する候補。費用承認なし。公式Auto Setupの対応表はUnity 6.3までなので、本作6.5での互換性確認を購入判断より先に行うべき|
|既製アセット Male 4|公式Asset Store表示25米ドル、URP対応|比較用候補。既製の私服人物であり、今回の髪・衣装・顔の目標を満たすと確認できていない。購入推奨にはしない|
|Meshy 7.1 / Fal|価格APIは基本0.80米ドル/generation。テクスチャ・リグ・アニメーションを含む実費は設定別で追加確認が必要|造形試作用。顔のアップでAAA品質になる保証はない。前回接続アカウントは残高不足。有料ジョブ未実行|

有料であることは品質保証ではなく、無料であることも低品質の理由ではない。現時点で有料購入は保留。

## 今回実装した導入準備

- GanzSe生成ツールでHighFidelityCharacterProfile付き交換済みPrefabを上書きしない。
- 主人公の高品質インポートは有効なHumanoid Avatarと動作クリップを必須とし、GanzSeおよび旧骨格のGenericクリップを拒否する。既存プレイヤーを置き換える前に検査する。
- Build Hero Humanoid Animatorウィンドウを追加。実際のHumanoidクリップを割り当てて移動ブレンド、回避、剣3段、魔法、死亡を既存ゲーム入力へ接続するコントローラーを生成できる。
- 新しいアニメーション素材やリアル人物モデルを生成・導入したわけではない。独立C#コンパイルを確認した段階で、追加ツールのEditor実行・新モデルでの実機検証は未実施。

合格には、実際の交換モデルの顔アップ・全身・移動・剣攻撃のゲーム内撮影が必要。ツールの実装、三角形数、購入、単なるマテリアル変更を主人公完成の根拠にしない。
